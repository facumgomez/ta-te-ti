# Juego Ta-Te-Ti

Este repositorio contiene una aplicación web del clásico juego **Ta-Te-Ti**, desarrollada con **React.js** y Vite.

El proyecto forma parte de mi portfolio como desarrollador frontend y está orientado a practicar lógica de juego, manejo de estado y componentes interactivos.

---

## 📌 Descripción

Juego Ta-Te-Ti es una versión web del tradicional tres en raya.  
La aplicación permite a dos jugadores jugar alternadamente, con una interfaz simple y responsiva.

Esta implementación sirve como ejercicio práctico para aplicar React, hooks y lógica de UI dinámica.

---

## 🛠️ Tecnologías utilizadas

- React.js
- JavaScript (ES6+)
- CSS
- Vite
- Git y GitHub

---

## 🧩 Funcionalidades

- Tablero interactivo 3×3
- Turnos entre jugadores
- Identificación de ganador
- Reinicio del juego
- Diseño responsive

1. Clonar el repositorio

   `npm install`

3. Ejecutar el proyecto  
   `npm run dev`
